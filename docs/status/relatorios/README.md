# Relatórios das rodadas

Um arquivo por card trabalhado, com o nome `AAAA-MM-DD-<id-do-card>.md`. Cada relatório diz o que mudou,
as decisões tomadas (marcando o que é regra do jogo e o que muda decisão do João), a branch, como testar
no PC (`git fetch origin` + `git switch claude/<id>` + `npm install` + `npm run dev`) e o que precisa do João.
